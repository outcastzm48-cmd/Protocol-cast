## 📌 WHAT IS THIS?
Protocol Cast tests if websites can be used for tunneling. It checks protocols and HTTP payloads to see what works.

## 📖 ABBREVIATIONS EXPLAINED
SSL/TLS = Secure Sockets Layer. The website lock 🔒 Port 443
SNI = Server Name Indication. The website name inside the lock. Ex: google.com
SSH = Secure Shell. Safe way to control another computer
V2Ray/Xray = Software used to make tunnels
WS = WebSocket. Keeps one connection open
gRPC = Google's fast data protocol  
H2 = HTTP Version 2. Faster websites
QUIC = Google's fast UDP protocol
CDN = Content Delivery Network. Big companies that host websites
IP = Internet address of a website
CLI = Command Line Interface. You type commands
